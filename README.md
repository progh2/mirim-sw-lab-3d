# 3학년 교실 겸 SW 실습실 3D 워크스루

미림마이스터고등학교 3학년 교실을 SW 실습실로 겸용하는 환경 개선안을 시공 도면(A-101, 1:50) 좌표 그대로 3D로 지은 1인칭 워크스루입니다.

**바로 보기:** GitHub Pages 주소에서 열면 됩니다 (Chrome·Edge 권장, 첫 로딩 약 25MB).

## 조작
| 키 | 동작 |
|---|---|
| W A S D / 방향키 | 걷기 (Shift: 빠르게) |
| 마우스 | 둘러보기 |
| E / 클릭 | 스위치 누르기 · 문 열고 닫기 · 빈 의자에 앉기 |
| C | 앉은 자세로 낮추기 / 일어서기 |
| 1 · 2 · 3 | 아침 · 점심 · 저녁 |
| 4 · 5 | 교탁 가운데 · 일반 수업 배치 |
| 6 | 바닥 투시 (바닥 아래 LAN·전원 배선 보기) |
| 7 · 8 · 9 | 학생 책상 폭 70 · 80 · 90cm |
| 0 | 네트워크함 위치 (좌북쪽 ↔ 복도쪽 기둥) |
| Esc | 일시정지 |
| 휴대폰 | 왼쪽 스틱 이동, 오른쪽 드래그 시점, 탭으로 상호작용 |

앞문 옆 스위치
- 위: 아침 · 점심 · 저녁 (조명·창밖·시계가 바뀜)
- 아래: 교탁 가운데 (교사 책상 이동) · 일반 수업 (모니터 접기, 키보드는 서랍으로, 책 펴기)
- 오른쪽: 학생 책상 폭 70/80/90cm · 네트워크함 위치 · 바닥 투시

## 반영 내용
- 교실 6,600 × 8,400, 액세스플로어(문 앞보다 200 높음), 책상 18석 + 19번 예비 위치
- 자리마다 바닥 단자함, 모니터암(좌북쪽 클램프)을 따라 내려가는 전원·LAN·키보드·마우스 선
- 모니터 뒤 VESA 연장 브래킷 미니PC, 가림막 멀티탭, 철망 서랍, 책가방 후크
- 86" TV + 86" 전자칠판(밀착), 유리 보드, 노출 천장·가로 LED·냉난방기 1대
- 좌북쪽 통신 배선 덕트 → 네트워크함(스위치·라우터·패치패널) → 액세스플로어 아래 → 자리별 단자함 LAN 경로
- 양쪽 기둥, 복도 통창, 안쪽 여닫이 문, 복도 사물함, 태블릿 충전보관함, 공기청정기
- 치수 일부(천장고, 복도 폭, 문 위치 등)는 가정값입니다.
